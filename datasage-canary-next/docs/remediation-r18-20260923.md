# R18 核验记录：把领域方法补成可用的正向诊断

日期：2026-09-23｜依据：综合审查 V2.0 的 R18（批次 D / P1）｜负责角色：业务 owner＋分析师
前置：R12、R16（已完成）｜性质：方法结构补齐；业务阈值与真实解释仍需 owner 评审

## 1. 结论

- 补齐前：8 份领域方法（7 个受管域 + 跨域）的结构是「对象选择 → 最小证据 → 边界 →
  评审提问」。它们能说清「不许说什么」，但缺少把现象推进到**可验证解释与优先级**的链条。
- 本轮为这 8 份材料各补一节 **Diagnostic path**，固定六段：
  **业务目标 → 候选解释（明确标为假设）→ 区分证据 → 重要性依据 → 可采取动作 → 停止条件**。
- 素材只来自已发布合同事实（指标口径、披露、账本/单位/币种规则）与本文件既有边界，
  **没有新增业务事实、没有编造阈值**；凡需要阈值或目标的地方都写成
  「需要 owner 基准，否则重要性未定」。
- 诊断链里出现的每个指标码都必须是 R16 登记册里的已注册指标——有守卫测试逐条校验，
  写不存在的指标会红。
- 未新建 planner、路线模板或自动因果判断器；深度按域不同，没有强行拉齐。

## 3. 逐域诊断链要点

| 域 | 目标（判断什么） | 关键候选解释（假设） | 主要区分证据 | 主要停止条件 |
| --- | --- | --- | --- | --- |
| delivery | 出库量/额/结构是否变化及还能支持哪种解释 | 量变、价/结构变、退货退款变、归属变、基期变 | 毛净额对比、订单数配金额 | 期间/口径/账本/单位币种不兼容，状态非完整 |
| receipt | 回款是否跟上出库与结算及缺口在哪 | 出库变、退货退款变、登记滞后或口径不同、结构变 | `delivery_receipt_comparison`、同期出库配净收款 | 口径不可比、币种不可隔离、能力未受管（现金/催收质量） |
| receivable | 应收规模与账龄结构、谁在背 | 销量增长、回款放缓、账龄迁移、主数据/组织变化 | 同口径账龄带、快照配账期、同期回款 | 缺信用政策/账期、快照时效未知、数量跨单位 |
| target | 目标达成与缺口位置（不评人、不评目标公平性） | 出库变、目标版本变、范围/组织变、账本不一致 | 完成率配目标额、同指标客户分解、完整缺口分解 | 账本/范围/期间/单位不兼容、目标缺失或为零、未完结 |
| inventory | 库存资金占用、账龄与结构（不是健康结论） | 采购快于销售、销售放缓、计价口径不同、慢池变化、覆盖不足 | 当前值配月末快照、账龄、周转、慢池计数 | 跨单位相加、成本覆盖不全、快照期间错配 |
| profit | 选定粒度的收入/毛利/费用覆盖及动因 | 量变、价折变、成本变、退货变、归属变 | 同粒度收入成本毛利配费用组件与覆盖 | 粒度/期间混用、费用缺失被补零、币种未隔离 |
| pattern_matching | 关联到任务/人员的金额与断链位置 | 匹配规则命中少、窗口不同、身份未知/冲突、截断、重复归属 | 任务关联额配人员归属额、任务汇总、未知/冲突计数 | 时间基准非已验证、身份冲突、截断、问因果或绩效 |
| cross-domain | 真正跨域的经营问题（不假装同一账本） | 量/价/结构变、时点或归属差异、单侧口径更窄 | 同窗口两个可比指标 + 一个能分离解释的组件 | 两侧无法可比、一侧不完整、问因果或健康结论 |

## 4. 本轮没有做（明确边界）

- 未改任何指标口径、合同或引擎行为。
- 未替业务定阈值、目标或重要性标准；写到需要基准处一律标注「需要 owner 基准」。
- 未删除任何证据边界，也未新增自动因果判断。
- 8 份材料里既有的 `Owner confirmation remains needed ...` 各项**仍未确认**，见第 5 节。

## 5. 需要业务 owner / 分析师确认的（真实评审）

| # | 待确认 | 影响 |
| --- | --- | --- |
| 1 | 逐域跑一次开放题评审：从现象出发，看是否真能推进到可验证解释与优先级（例如「某客户 8 月出库额降 20%」→ 量价拆分 → 退货与账期核对 → 下一步证据） | R18 验收的核心，离线无法替代 |
| 2 | 各域「候选解释」清单是否符合业务实际（增减或排序） | 防止方法引导到业务上不成立的解释 |
| 3 | 重要性依据：各域可用的基准/目标来源（目标台账、预算、历史同类均值等） | 没有基准只能给描述，不能给优先级 |
| 4 | 各域 `Owner confirmation remains needed` 项（回款登记 vs 实结含义、汇率口径、组织等价、目标版本归属、快照时效、账龄与债务对账、周转期、慢池业务含义、利润关账状态等） | 决定方法能否从「候选」提升为正式 |
| 5 | 领域深度差异是否接受（不要求七域同深，但需确认哪几域先做深） | 验收允许不等深，需 owner 指定优先域 |

## 6. 回退

- 逐域回退：删除对应材料的 `## Diagnostic path` 一节即恢复原状；其余基础能力与守卫不受影响。
- 不改合同、不改引擎、不动既有回归用例集合（除为 R13 对齐的那一条断言）。
