# R19 核验记录：跨域推理与高影响建议的验收准备

日期：2026-09-23｜依据：综合审查 V2.0 的 R19（批次 D / P1）｜负责角色：业务 owner＋专家评审
前置：R17、R18（已完成）｜性质：离线验收案例与边界断言；模型答案评审需专家执行

## 1. 结论

- R19 要求的四个配对（出库-利润、出库-回款应收、库存-销售、目标-实际）此前**没有离线案例**：
  既有 18 案里只有 B13「跨域经营判断」，而它自己也标注「没有执行跨域百分比场景或经营判断」。
- 本轮把这四个配对做成**独立手写期望**的验收案例 B19–B22，另加两个边界案例：
  B23（相关性反例，结构贡献≠因果）与 B24（证据不足仍继续合理分析但不给健康结论）。
  夹具从 18 案扩到 24 案，期望值仍为手写、与插件合同无关，并由测试逐条独立复算。
- 每条案例都写死了「必须做到」与「禁止」两类属性，直接对应 R19 的验收条件：
  结构贡献与因果分开；回款不当现金流；核算未完成不叫完整净利；建议说明条件/风险与复核点；
  重大动作不自动执行。
- 离线能做的到此为止：**案例与边界是已知的，模型实际怎么答仍未被评审**（`execution_status:
  not_run`、`independent_business_review_status: pending`），这一点没有被伪装成通过。

## 3. 新案例的期望与边界

| 案例 | 配对／场景 | 独立手写期望 | 必须做到（节选） | 禁止（节选） |
| --- | --- | --- | --- | --- |
| B19 | 出库-利润 | 同月同部门出库 −20 万；记录毛利 40 万→30 万（−10 万） | 同口径分别给出；毛利变化先作观察；给可区分下一步证据；说明记录毛利≠已关账净利 | 把出库下降当作毛利下降的原因；把记录毛利叫净利；跨粒度相减 |
| B20 | 出库-回款应收 | 出库 +20 万；应收快照 +30 万 | 三套口径分别给出；说明回款登记额不是现金流；应收变化是快照事实 | 把回款登记额称为现金流或流动性；未对账就断言回款没跟上 |
| B21 | 库存-销售 | 库存 +100 万；出库 +20 万 | 快照与期间各自口径；数量按单位保留；周转需完整输入 | 用同向增长证明压货；跨单位相加；缺输入给周转评级 |
| B22 | 目标-实际 | 目标 300 万、实际 270 万、缺口 30 万 | 同账本同期间同口径；缺口按同指标客户分解；未完结并列状态 | 跨账本相除；缺失目标当零；把缺口归因到业务员能力 |
| B23 | 相关性反例 | 整体 +14 万；A +21 万（贡献 150%）、B −7 万 | 如实呈现 >100% 贡献；要求机制/区分证据 | 断言某客户带动整体；把边际分解当作重叠证据；仅凭同向变化支持因果 |
| B24 | 证据不足 | 利润不可用（未受管），出库与库存有效 | 明确利润缺失不虚构；保留有效分支；无基准则只作描述；给核对与复核点 | 用出库增长判定健康；用相邻指标推断利润；把进行中期间当已结束 |

## 4. 与验收条件、禁止扩张的对应

| R19 验收条件 | 本轮落地方式 |
| --- | --- |
| 结构贡献与因果分开 | B19/B23 的必做与禁止属性；`cross-domain-analysis.md` 与 `answer-boundary` 的既有限制 |
| 回款不当现金流 | B20 的禁止属性（含「不得作为现金或流动性结论」） |
| 核算未完成不叫完整净利 | B19 禁止把记录毛利称为净利；B24 禁止推断利润 |
| 建议说明条件/风险 | 各案例要求给出可区分证据与负责人；B24 明确要求复核点 |
| 重大动作不自动执行 | 沿用 B18 的既有边界，新案例不引入任何执行动作 |
| 不把 scorecard 变硬路由 | 新案例均以开放题形式给出，未引入固定步骤或必查清单；守卫断言不含「按顺序/第一步」类字样 |
| 不统一不兼容口径迁就叙事 | B20/B22 明确禁止跨口径相除与跨账本比较 |
