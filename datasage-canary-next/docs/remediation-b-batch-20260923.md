## 任务明细

### R03 补导出依赖闭包（F01，P1）

- 改动：`scripts/datasage_source_export.py`（白名单补 6 个价格模块 + `public_fields.py`
  与 11 个配套测试）、`tests/test_source_export.py`（新增闭包枚举与白名单断言）。
- 修前失败：在 `48649bd` 上执行导出器得到的产物缺少 6 个模块，4 条直接相对导入断裂
  （`local_report.py:308/319`、`workflow_io.py:494/497`）；新增用例在改前副本上 2 项失败。
- 修后验证：真实导出产物 314 个文件，6 模块齐备，插件包 79 个模块，断边 0；导出测试
  11 项通过（1 项因 Windows 无符号链接权限跳过，属既有环境跳过）。
- 影响范围：仅源码审查导出器的白名单与导出测试；不改变查询、运营与投递行为。
- 回退：单独回退导出脚本与导出测试；此前已导出的旧包标记过期。

### R04 Ground Truth 事实 ID 唯一性（F02，P1）

- 改动：`plugins/datasage-query/e2e/answer_ground_truth.py` 在 `normalized_facts` 之后
  增加标准化 ID 唯一性拒绝；`tests/test_answer_ground_truth.py` 增加重复 ID、标准化碰撞
  与「独立 ID 缺值必须失败」的正反对照。
- 修前失败：改前副本上 3 项失败（重复 ID 未拒绝、`" target "` 碰撞未拒绝）。
- 修后验证：17 项 GT 测试全部通过；重复 ID 标准输入直接报错，独立 ID 下遗漏目标值判失败。
- 影响范围：仅离线评分与 GT 夹具校验，不进入在线回答链；JSON 真源的新旧发布结果不受影响。
- 回退：评分代码与夹具版本一起回退；旧评分结果不得作为新门禁证据。

### R05 数值断言的否定/未知/引用误判（F04，P1）

- 改动：同文件新增「非断言」判定——只检查标签到首个数字之间的连接词是否包含否定、
  引用、假设或未知标记；仅由这类语句承载的数值转 `not_verified`（转人工/独立评审路径），
  不再计入数字维度通过。
- 修前失败：改前副本上 4 个语义变形用例失败（否定、未知参考、引用、未达到均判 passed）。
- 修后验证：4 个变形用例均不再 passed 且整体转 `not_verified`；正向对照（数值后出现
  「参考口径」等标记）仍判 passed，证明判定范围只限连接词而非全文关键词黑名单。
- 影响范围：仅评分语义；门禁维度结构、`unknown` 事实分支与既有 12 项 GT 用例行为不变。
- 回退：回退本次评分逻辑，保留新增反例作为未关闭问题。

### R06 隔离查询与运营的启动合同依赖（F03，P1）

- 改动：`plugins/datasage-query/contract_store.py` 把固定合同集分为查询组（严格）与
  运营/legacy 组（容错，按文件记录 `operator_failures`）；`runtime_health.py` 在就绪
  状态中显式暴露 `operator_contracts_loaded`。
- 修前失败：改前副本上 2 项错误（`contract_snapshot_status` 无运营状态键；运营文件损坏时
  查询初始化被拖垮）。
- 修后验证：运营文件格式错误时 3 个查询工具仍完成注册，状态显示运营合同不可用且
  `file_count` 少 1；运营入口读取仍以 `operator_contract_unavailable` 失败关闭；
  查询关键合同损坏时注册整体拒绝（既有行为保持）。10 项快照测试通过。
- 影响范围：合同快照与运行诊断；合同字节、digest、重启刷新语义与查询执行路径不变。
- 回退：回退消费分组与入口修改，恢复旧快照；回归记录标明隔离缺口。

### R07 合同缓存的不可变边界（F05，P2）

- 改动：同文件新增递归只读视图（`dict`/`list` 子类，仅禁用就地修改，保留 `isinstance`
  与 JSON 语义），`parse_yaml_cached` 发布只读视图；`__copy__`/`__deepcopy__` 提供显式可变副本。
- 修前失败：改前副本上 2 项失败（同一缓存对象可被改写并传播给后续读者）。
- 修后验证：嵌套 mapping/list 就地修改抛 `TypeError`，第二读者读到原值；并发 32 次读取
  一致；`deepcopy`/`json.dumps` 等既有消费方式等价（`test_business_contracts` 80 项通过）。
- 影响范围：只读消费者语义等价；如需修改须显式复制。digest 仍表示源字节，不代表内存不可变。
- 回退：独立回退只读视图实现；清理实验缓存，不修改磁盘合同。

### R08 拒绝重复显式 YAML 键（F06，P2）

- 改动：同文件新增安全 Loader，按层拒绝重复显式键；先检查本层键再展开 `<<` 合并，
  保留合法 anchor/alias 与显式覆盖语义。
- 修前失败：改前副本上 2 项错误（合成重复键被静默取后者）。
- 修后验证：顶层与嵌套重复键均被拒绝；不同层同名合法；`<<` 合并及显式覆盖结果正确；
  非映射根仍失败关闭；当前 15 份合同（含 JSON）无新增误报。
- 影响范围：合同解析入口；仍是安全加载，不引入新语义语言，不替换 YAML 机制。
- 回退：回退 Loader 改动并保留重复键检查为阻塞测试。

### R09 公共结果字段归属迁移（F07，P2/结构）

- 改动：新增低依赖模块 `plugins/datasage-query/public_fields.py` 承载公共结果字段真源
  （只读 frozenset）；`tools.py` 改为引用该模块；`contracts.py` 去掉对执行中心的返回导入。
- 修前失败：改前副本探针显示仅做目录投影即加载执行中心 `tools`（模块图反向边）。
- 修后验证：同一探针显示目录投影只加载 `public_fields`，不加载 `tools`；源字符串与导出
  白名单同步补齐该模块；依赖测试 18 项通过（含该隔离断言）。
- 影响范围：字段可见性与序列化结果不变（既有 catalog 用例通过）；属结构移动，不改业务口径。
- 回退：回退常量迁移与导入，单独提交便于定位。
