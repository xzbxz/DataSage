## 5. 本轮自查修掉的测量缺陷

1. 模块引用检测只认 `from .mod import` 与带引号的名字，漏掉 `from . import a, b` 与
   `import_module(f"{PACKAGE}.mod")` 形态 → 曾报出 8 个假孤儿；改为**词边界提及**计数。
2. 指标引用靠猜前缀 → 只找到 6 个；改为以 R16 登记册的全量码表逐词匹配（63/215）。
3. `git log` 的 pathspec 用了仓库根相对路径，而 `-C` 已进入 profile 子目录 → 中位数全部为 0；
   改为 profile 相对路径后得到真实中位（6/4/5）。
4. 补丁脚本把 `\b` 写成了**退格控制字符**，导致检测恒为 0；`cat -A` 定位后修正。
5. 自指测量：登记册自身在 `fixtures` 计数内，写一次数字就变一次 → 排除自写文件，`write→check`
   现为幂等。
