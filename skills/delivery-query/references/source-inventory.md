# 出库与下单语义来源

## 当前权威来源

- `planner-contract.yaml`：模型正常问答使用的精简规划合同，只包含业务意图、受控指标与维度代码、默认范围、分析配方和回答边界。
- `semantics.yaml`：查询插件使用的完整物理执行合同，保存已确认公式、字段来源、状态、时间、关联和粒度；正常业务问答不加载、不引用其物理实现。
- `common-data-foundation/references/datasets.yaml`：事实粒度、主键、允许字段、禁用字段和多对一主数据关联。
- 已确认业务规则：毛出库使用 `delivery_time` 且 `bill_status=6`；退货使用 `statement_time`、`status=4`、`complnt_type=1`、`channel_type=1`；默认销量/出库为同期毛出库减同期退货；下单使用 `sale_time` 且不排除状态。
- 已确认字段规则：出库数量 `sorted_goods_num`、出库卷数 `sorted_piece_num`、下单数量 `sale_goods_num`、下单卷数 `sale_piece_num`；备货使用 `is_ready` 并包含备货与试备货；事实 `is_self` 废弃。
- 普通查询使用交易事实账：毛出库和退货分别使用各自事实的 `sales_id/sales_name`；只有目标、协作、分摊或明确分摊业绩才进入目标域的业务员分摊账。
- 已确认仓库规则：默认“按仓库看出库”使用实际仓库净流量，条码毛出库按实际出库仓，退货按实际退入仓扣减。
- 2026-07-20 Profile owner 决定移除按原出库仓、来源出库仓或责任仓归因能力；此类问题不查询，也不得用实际仓库净流量静默替代。
- 已确认币种规则：金额默认人民币；用户只说原币时自动按币种分组，明确币种时限定该币种；同币种内计算净额，不得汇总不同原币。
- 已确认查询模式：当前发布面仅支持 metric mode。业务汇总、单数、比例、排名、比较和净值必须使用登记指标；模型不可提交 dataset、物理字段或明细计划。出库、下单和退货指标仍继承各自固定时间、状态与内部客户口径。
- 已确认运行边界：交易查询需要解析出的起止时间，但不设置固定最大查询跨度；`data_updated_at` 不作为对外能力、回答必填项或查询阻断条件。

## 开放分析可用证据

- 汇总：净出库、毛出库、真实条码毛出库、仓库净流量、退货的金额/数量/卷数，以及各自已确认的非重复单据数。
- 趋势：工具控制的按日或按月时间分组。
- 排名与结构：客户、产品、业务员、部门、组织，以及仓库、批次、条码、缸号等受控物理维度。
- 变化来源：同一指标和维度的当前期间与等长前期比较，返回当前值、前期值、差额和变化率。
- 单实体分析：通过客户、产品或业务员过滤复用同一组确认指标。

## 限制

- 下单和出库使用不同时间字段；同期差额不是订单级履约率或转化率。
- 拆单后出库单可能多于下单单据，当前数据不做原始订单还原。
- 默认净出库是当期流量口径，不把退货追溯回原出库月份。
- 普通业务维度使用销售明细事实；仓库、条码、批次、缸号和单匹等物理维度使用条码事实自身措施。禁止一对多连接条码后重复汇总销售明细金额或数量。
- 仓库净出库描述实际仓库出入流量，不代表来源出库仓或责任仓归因；用户要求后者时必须说明当前不提供，不能发起查询或替换问题。
- 仓库族、批次、条码和次品项支持期间净流量；其中仓库族按实际出库仓与实际退入仓，批次、条码和次品项按两侧事实自身记录值。原条码和缸号只支持显式毛出库，净出库请求不得降级。
- 原币仓库净流量要求币种筛选或分组，不得汇总不同原币。
- 单据类型分析中，毛出库使用 `bill_type`，退货使用 `sale_bill_type`，两侧分别聚合后统一输出为 `bill_type`。
- 当前主数据属性不是交易时点快照；用于历史分析时必须说明。
- 结构变化只能说明“变化来自哪些已观测维度”，不能证明客户意图、市场原因或人员责任。
- 出库拆分表的有效明细覆盖、复合键唯一、无孤儿和金额对平由ETL负责；本域不使用拆分表，目标域按明确 attribution_mode 使用正式拆分表。
- 当前发布面没有 dataset mode 或模型侧明细计划；任何汇总、净值、比率或跨事实结果都必须使用登记指标。
- 单次治理指标查询的最大跨度与更长分析处理方式，以版本化的共享查询策略为唯一权威；同时继续遵守明确时间范围、查询超时、返回行数上限和数据库保护。
- 不向业务用户主动解释表同步时间；`data_updated_at` 为空不代表数据过期，也不构成失败。

本文件只记录规则来源、汇总验证结论和能力边界，不保存客户、订单、条码或金额明细。
